# Honkai: Star Rail | Planar Ornament Sets

รวม 28 เซ็ต ครบตามหมวด `PLANETARY ORNAMENT SET` บนหน้า Prydwen ที่เปิดตรวจเมื่อ 26 กันยายน 2026 เวลาไทย (หน้าเว็บระบุอัปเดต 24 กันยายน 2026). ([Prydwen](https://www.prydwen.gg/star-rail/guides/relic-sets)) เก็บชื่อและข้อความโบนัสภาษาอังกฤษจากแหล่งข้อมูล พร้อมหัวข้อภาษาไทย เพื่อใช้เป็นฐานข้อมูลอ้างอิงสำหรับ AI.

## ขอบเขตและวิธีอ่าน

- **ประเภท**: PLANETARY ORNAMENT SET. ([Prydwen](https://www.prydwen.gg/star-rail/guides/relic-sets))
- **โบนัสที่รวม**: 2 ชิ้น พร้อมตัวเลข เงื่อนไข ระยะเวลา และข้อจำกัดที่ข้อความต้นทางระบุ. ([Prydwen](https://www.prydwen.gg/star-rail/guides/relic-sets))
- **ขอบเขตข้อมูล**: เป็นฐานข้อมูลโบนัสเซ็ต ไม่ใช่ตาราง Main Stat/Substat หรือรายชื่อชิ้นส่วนแต่ละสล็อต และไม่ใส่คำแนะนำตัวละครหรือข้อมูลที่ต้นทางไม่ได้ระบุ.
- **ความครบถ้วน**: ครบตามรายการที่แหล่งข้อมูลแสดง ณ วันที่ตรวจ ไม่ได้อ้างว่าตรวจสถานะเปิดตัวทุกเซ็ตในเกมแยกต่างหาก.
- **ข้อกำหนดสำหรับ AI**: รักษาข้อจำกัดการซ้อนทับ สแต็ก เป้าหมาย ระยะเวลา และเกณฑ์ Stats ตามข้อความแต่ละเซ็ต ห้ามใช้กฎของเซ็ตหนึ่งแทนอีกเซ็ต.
- **แหล่งข้อมูล**: ไม่ใช้ Game8 ในการค้นคว้าหรือสร้างไฟล์ชุดนี้.
