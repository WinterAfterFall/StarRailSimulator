# Honkai: Star Rail | Light Cones: Elation

ฐานข้อมูล Light Cone Path Elation จำนวน 13 ชิ้น ครบตามรายการบนหน้า Prydwen ที่เปิดตรวจเมื่อ 26 กันยายน 2026 เวลาไทย (หน้าเว็บระบุอัปเดต 24 กันยายน 2026). ([Prydwen](https://www.prydwen.gg/star-rail/light-cones)) หัวข้อและคำอธิบายวิธีอ่านเป็นภาษาไทย ส่วนชื่อและข้อความความสามารถเก็บภาษาอังกฤษจากแหล่งข้อมูลเพื่อใช้เป็นเอกสารอ้างอิงสำหรับ AI.

## ขอบเขตและวิธีอ่าน

- **จำนวนตามดาว**: 5 ดาว 7 ชิ้น; 4 ดาว 4 ชิ้น; 3 ดาว 2 ชิ้น. ([Prydwen](https://www.prydwen.gg/star-rail/light-cones))
- **ความสามารถ**: คงเงื่อนไข ตัวเลข จำนวนสแต็ก ระยะเวลา เป้าหมาย และข้อจำกัดตามข้อความ Prydwen ไม่ย่อเหลือเพียงบทบาทของอาวุธ. ([Prydwen](https://www.prydwen.gg/star-rail/light-cones))
- **Superimposition**: ชุดตัวเลขห้าค่าที่คั่นด้วย `/` อ่านจากซ้ายไปขวาเป็น S1, S2, S3, S4, S5; ตารางท้ายรายการแยกค่าที่พบในข้อความโดยตรง ไม่ประมาณค่าระหว่างขั้น. ([Prydwen](https://www.prydwen.gg/star-rail/light-cones))
- **Stats**: HP / ATK / DEF เป็นค่าจำนวนเต็มที่แหล่งข้อมูลแสดง ไม่ปรับการปัดเศษหรือเติมทศนิยม; หน้ารวมไม่ได้กำกับเลเวลบนการ์ดแต่ละชิ้น จึงระบุเลเวลในชุดข้อมูลนี้ว่า `ไม่กำกับในหน้ารวม`. ([Prydwen](https://www.prydwen.gg/star-rail/light-cones))
- **บริบทเลเวล**: Light Cone มีเลเวล 1–80 ตามคู่มือ Prydwen. ([Prydwen](https://www.prydwen.gg/star-rail/guides/light-cones)) ตัวอย่าง In the Name of the World มีค่า 1,058 HP / 582 ATK / 463 DEF ตรงกับ Lv.80/80 Ascension 6 ใน Wiki; การตรวจตัวอย่างนี้ไม่ใช่การตรวจตารางเลเวลของทุกชิ้น. ([Honkai: Star Rail Wiki](https://honkai-star-rail.fandom.com/wiki/In_the_Name_of_the_World))
- **การเปิดใช้ Passive**: ตัวละครต้องอยู่ Path ตรงกับ Light Cone จึงได้รับความสามารถ; ใส่ต่าง Path ได้เฉพาะค่าสถานะ. ([Prydwen](https://www.prydwen.gg/star-rail/guides/light-cones))
- **ขอบเขตความครบถ้วน**: ครบตามรายการที่แหล่งข้อมูลแสดง ณ วันที่ตรวจ ไม่ได้อ้างว่าตรวจสถานะเปิดตัวทุกชิ้นในเกมแยกต่างหาก และไม่ใส่ข้อมูลที่ไม่มีอยู่ในรายการต้นทาง.
- **ข้อกำหนดสำหรับ AI**: ห้ามเดาค่าที่ไม่ได้ระบุ ห้ามแทนค่าทุกชิ้นด้วยสูตร scaling กลาง และห้ามใช้ไฟล์รุ่นเก่ามาเติมข้อมูลโดยไม่ตรวจสอบ.
- **แหล่งข้อมูล**: ไม่ใช้ Game8 ในการค้นคว้าหรือสร้างไฟล์ชุดนี้.
