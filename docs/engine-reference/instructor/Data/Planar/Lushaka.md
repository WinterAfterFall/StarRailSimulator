## จุดที่ควรรู้

- **ER เขียนที่ฟิลด์ `energyRecharge` โดยตรง** ไม่ใช่ `statsType[Stats::ER]` — เป็นช่องคนละช่อง ต้องระวังเวลา grep หาว่าอะไรเพิ่ม ER ให้ตัวละคร
- **ผลตกที่ `charUnit[1]` เสมอ** (เพื่อนช่องแรกตามลำดับที่ประกอบทีม) เช็คด้วย `ptr->atvStats->num != 1` · เป็นเซ็ตเดียวในโฟลเดอร์ที่ผลขึ้นกับ **ตำแหน่งในทีม** → การสลับลำดับตัวละครตอนประกอบทีมเปลี่ยนผลลัพธ์
- บัฟลงด้วยการเขียน `statsType` ตรง ๆ ไม่ผ่าน `buffSingle` → **ไม่ยิง `statsAdjust`** ถ้าเพื่อนช่องแรกมี trace ที่คำนวณจาก ATK แบบ live (ดู `../Character/Abundance/Gallagher.md`) ค่าจะไม่ตามไปด้วย
