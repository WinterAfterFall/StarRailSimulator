# `src/Defination/Data/Character/Preservation/`

**ไม่มีตัวละครที่ใช้งานได้เลย**

มีไฟล์เดียวคือ `Aventurine.h` ซึ่ง **ถูกคอมเมนต์ทิ้งทั้งไฟล์** (257 บรรทัด ไม่มีบรรทัดที่ไม่ใช่คอมเมนต์เลย) และ `All_Preservation_char.h` ก็คอมเมนต์ `#include` ทิ้ง

ดู `Aventurine.md` สำหรับรายละเอียด — รวมถึงตารางเทียบ API รุ่นเก่ากับรุ่นปัจจุบัน ซึ่งเป็นหลักฐานว่า engine เคยเปลี่ยนสถาปัตยกรรมครั้งใหญ่

## ทำไมยังไม่มี

kit ของตัวละคร Preservation แทบทุกตัวเป็นสาย **shield** ซึ่ง **engine ยังไม่มีระบบสร้างโล่** — มีแต่ `decreaseSheild()` ไม่มีโค้ดที่เพิ่ม `currentSheild`

ดู `../../../future-improvements.md` ข้อ 2 ซึ่งระบุ "ปลด comment Aventurine" ไว้เป็นงานปลายทางของข้อนั้น
