# BuffStack

ระบบ `BuffStack` ใช้เพิ่มหรือลดค่าบัฟตามจำนวน stack ที่เปลี่ยนแปลง โดย stack ของแต่ละยูนิตถูกเก็บแยกตาม `Stack_Name` และจำนวน stack ใหม่จะไม่เกิน `Stack_limit`.

## การทำงานหลัก

- `calStack` คำนวณจำนวน stack ที่เพิ่มได้จริงจากค่าเดิม, จำนวนที่ขอเพิ่ม และขีดจำกัด จากนั้นคืนค่าจำนวนที่เพิ่มจริงพร้อมอัปเดต stack
- `buffStackSingle` นำจำนวน stack ที่เพิ่มจริงไปคูณค่าของ `BuffClass` หรือ `BuffElementClass` แล้วเรียกใช้บัฟกับเป้าหมาย
- `buffStackChar` ใช้กับตัวละครและเมมอสไปรต์ของตัวละครนั้นตามลำดับ
- `buffStackAllMemosprite` ใช้กับเมมอสไปรต์ทุกตัวใน `charList` โดยต้องส่งพอยน์เตอร์ของเมมอสไปรต์ (`each2.get()`) ให้ `buffStackSingle` ไม่ใช่พอยน์เตอร์ของเจ้าของเมมอสไปรต์

## การรีเซ็ต

ฟังก์ชัน `buffResetStack` จะลบบัฟตามจำนวน stack ปัจจุบัน แล้วตั้งค่า stack ของชื่อดังกล่าวกลับเป็นศูนย์
