# DebuffStack

`Stack_increase` รองรับทั้งค่าบวกและค่าลบ ค่าลบใช้สำหรับตัวละครที่ลดดีบัฟทีละ stack เช่น `-1` โดยส่งผ่าน `debuffStackSingle()` หรือฟังก์ชันกระจายเป้าหมายที่เกี่ยวข้อง

การคำนวณจะจำกัดค่า stack ให้อยู่ในช่วง `0` ถึง `StackLimit` และคืนจำนวนที่เปลี่ยนแปลงจริง ดังนั้นหากมี 1 stack แล้วสั่งลด 3 จะลดจริงเพียง 1 และเหลือ 0 ค่าที่นำไปคูณ `debuffSet` จะเป็นค่าที่ลดจริง ไม่ใช่ค่าที่ร้องขอเกินขอบเขต
