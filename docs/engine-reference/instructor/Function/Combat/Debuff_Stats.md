# Debuff Stats

ใน `debuffSingleMark()` ดีบัฟความเร็วต้องถูกนำไปใช้กับ `enemy` ซึ่งเป็นเป้าหมายเสมอ ไม่ใช่ `ptr` ผู้แจกดีบัฟ เช่นเดียวกับ `debuffSingleApply()` และฟังก์ชันดีบัฟรูปแบบอื่น

`weaknessApplyChoose()` จะ clamp `amount` ให้อยู่ระหว่าง 0 และ 7 ธาตุ โดยไม่เกินจำนวนธาตุที่เลือกได้จริง เพื่อไม่ให้ configuration ที่ขอมากเกินไปหรือเป็นค่าติดลบทำให้เข้าถึงข้อมูลนอกขอบเขต
