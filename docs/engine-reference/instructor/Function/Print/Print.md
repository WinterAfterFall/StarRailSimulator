# `src/Defination/Function/Print/Print.h`

`Print()` เป็น manual debug สำหรับตรวจว่าโปรแกรมรันถูกต้องตามที่คาดหรือไม่ (user ยืนยัน 2026-09-21) ทำงานเฉพาะเมื่อ `Print_Atv` เปิดอยู่ และพิมพ์ ATV ปัจจุบัน, ชื่อ/จำนวนเทิร์นของยูนิตที่กำลังเดิน, SP, toughness ของศัตรูช่อง 1–2 และสแต็ก `FireFly_E2` ของตัวละครช่อง 1 ข้อมูลท้าย ๆ เป็นค่าที่ hardcode สำหรับการตรวจด้วยมือในรูปแบบปัจจุบัน ไม่ใช่รายงานทั่วไปสำหรับทุกทีม

`printRoundResult()` พิมพ์ดาเมจรวมและดาเมจเฉลี่ยปัจจุบัน, substats และจำนวนเทิร์นรายตัวละคร ก่อนรวมยอดทั้งทีม

`printSummaryResult()` พิมพ์ผลที่เก็บเป็นค่าสูงสุดของแต่ละตัวละครและรวมทีม แยกชนิดดาเมจจาก `maxRealTimeDmg` / `maxNonRealTimeDmg`, สะสมยอดรายศัตรู และแสดงยอดสะสมเมื่อโฟกัสศัตรู 1 ถึง N ตัว
