# `src/Defination/Class/ActionData/`

ข้อมูลในโฟลเดอร์นี้แบ่งเป็นคลาสฐานของแอ็กชัน (`ActionData`), แอ็กชันฝ่ายเรา (`AllyActionData` และชนิดโจมตี/บัฟ), แอ็กชันศัตรู (`EnemyActionData`) และ helper ตรวจชื่อ เจ้าของ และชนิดแอ็กชัน (`ActionDataDefine`)

สำรวจไฟล์โค้ดในโฟลเดอร์ครบแล้ว ณ 2026-09-21 รายละเอียดอยู่ในเอกสารชื่อเดียวกับแต่ละไฟล์; `Library.h` เป็น include aggregator ไม่มี logic เพิ่ม
